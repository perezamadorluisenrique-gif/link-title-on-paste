# Changelog

The release workflow uses the section named after the version being released
as the release description, so every version needs one. `npm version <x.y.z>`
renames the `Unreleased` heading below to that version.

## Unreleased

- New command "Add titles to the links in this note or selection": turns every bare web address into a titled link, three requests at a time, in a single undo step.

## 0.1.1

- Settings now appear in Obsidian's settings search (declarative settings API on 1.13 and later).
